# AI Coding Camp: Starter App

This is your starting point at the Computhink AI Coding Camp.
You build your own web app from it, one feature at a time, with GitHub Copilot.

## What is in here

| File | What it does |
|---|---|
| `index.html` | What you see: boxes, buttons, lists |
| `style.css` | How it looks: colours, fonts, spacing |
| `script.js` | What it does: add, save, count, warn |
| `brief.md` | Your plan, copied from your MVP Plan Worksheet. Copilot reads it. |
| `.github/copilot-instructions.md` | The camp rules Copilot follows. Please leave this file alone. |
| `.devcontainer/devcontainer.json` | Sets up your Codespace with Copilot ready to use. Please leave this file alone. |

## Your public link

Once GitHub Pages is switched on, your app lives at:

`https://<your-username>.github.io/<your-repo-name>/`

A Save (Commit + Sync) can take up to 10 minutes to show there.
Press Ctrl + Shift + R to see the newest version.

## Keep it safe

Your app and this repository are public.
Use made-up names and data only.
No real names, photos, addresses or school names.
